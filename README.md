# MyRoutine

## Kotlin mobile app for daily habit tracking with a home screen widget for visibility and reminders.

## Features
1. **Two Habit Types:** Create simple **"Yes/No"** routines or **"Measurable"** routines with custom numerical targets and units.
2. **4-Day Dashboard:** View and edit habit progress for today and the previous three days in a dynamic, color-coded table.
3. **Customization & Sorting:** Assign custom colors to habits and sort the main dashboard by Name or Color.
4. **Interactive Checkmark Widget (2x2):** A home screen widget to instantly toggle a habit's daily status without opening the app.
5. **Visual History Widget (3x2):** A home screen widget that displays the recent completion grid for a specific routine.
6. **Daily Reminders:** Set custom, automated notification times for individual habits during creation.
7. **Automated Midnight Reset:** Automatically resets today's completion status and shifts the visible calendar dates at exactly 12:00 AM.
8. **Real-Time Syncing:** Instant bidirectional state updates between the app dashboard, the Checkmark widget, and the History widget.
9. **Offline Local Storage:** Fully local data persistence using **SharedPreferences** to save routines, progress, and widget bindings.

## Application Examples
1. Workout gym sets tracking
2. Daily habits (e.g., LeetCode or Jogging)
3. Medication reminders
